invgen

Write invoices in markdown, export clean PDFs. Live preview, native on Linux.

One-click install

Open this file with your software center (GNOME Software, Discover, Mint Software Manager):

Install invgen

Command line

flatpak install --user https://ldolberg.github.io/invgen/io.github.ldolberg.invgen.flatpakref
flatpak run io.github.ldolberg.invgen

Updates arrive with flatpak update. The runtime comes from Flathub.

Or add the repository

flatpak remote-add --user --if-not-exists invgen https://ldolberg.github.io/invgen/invgen.flatpakrepo
flatpak install --user invgen io.github.ldolberg.invgen

The repository is signed; the public key is invgen.gpg.

Source, docs and release tarballs: github.com/ldolberg/invgen
